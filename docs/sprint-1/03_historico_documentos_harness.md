## 2. Contradicoes encontradas

- Assets antes estavam em `img/` e depois foram copiados para `public/img/`; o app Vite atual usa `/img/...` a partir de `public/img`.
- Alguns documentos intermediarios diziam que `public/img` estava vazio e que E2E falhava por ausencia de `PTS`; documentos posteriores registram correcao.
- Stage antes tinha painel Arduino e controles; no estado atual, Stage nao abre Web Serial.
- Reset manual/fisico era parte do fluxo inicial; no estado atual, Admin envia `RESET_HW` automaticamente.
- Mapeamento A/B mudou: docs antigos indicam `BT1PRESS -> A`, `BT2PRESS -> B`; estado atual calibra `BT1PRESS -> B`, `BT2PRESS -> A` para o evento fisico.
- APIs globais legadas (`GameBackground`, `GameIntro`, `QuizStage`, `ArduinoBridge`) foram substituidas por componentes/hooks/store React.
- `19_plano_admin_realtime.md` considerava WebSocket/Socket.IO; Sprint 1 final escolheu BroadcastChannel e nao criou backend.
- Alguns documentos recomendam fatias que ja foram executadas.
