# Harness 9.1 — SDD Operação Real, Admin, Visual e Infra

Pacote de prompts `.md` para executar o **Harness 9.1** do projeto **Dois Pesos, Duas Medidas**.

## Objetivo

Correção pós-Harness 9, com foco em operação real:

- estabilidade do Arduino no pré-show e na primeira rodada;
- botão manual visível para reset do Arduino no Admin;
- áudio do botão de vez;
- troca dos brasões dos cards por novos assets oficiais;
- mapeamento do novo banco de imagens/personagens;
- quarentena de imagens com fundo problemático;
- limpeza visual e operacional do Admin;
- reconstrução do evento Tribunal como modal full-screen;
- atualização da área de ajuda;
- criação de `.bat` seguro para iniciar o jogo no Windows.

## Como usar

Cole primeiro o conteúdo de `00_PROMPT_START_CHAT.md`.

Depois execute os prompts da pasta `prompts/` em ordem.

## Regra de ouro

Este Harness 9.1 não pode desmontar o Harness 9. Ele deve corrigir, estabilizar e polir apenas os pontos especificados.
