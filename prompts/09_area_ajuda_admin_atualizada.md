# Prompt 09 — Atualizar Área de Ajuda do Admin

## Objetivo

Reescrever ajuda do Admin para operação real.

## Conteúdo obrigatório

- Abrir Admin/Stage.
- Conectar Arduino.
- Testar mesas.
- Se Mesa A/B falhar.
- Usar fallback.
- Usar Resetar Arduino.
- Iniciar rodada.
- Botão de vez.
- 20s de resposta.
- Silêncio -10/+10.
- Tribunal.
- Validar resposta correta no Admin.
- Áudio.
- Emergência.
- Contingência.

## Tom

Humano, curto, prático, sem jargão.

## UI

Preferir seções colapsáveis, passos numerados e cards de emergência.

## Testes

Ajuda abre, textos-chave aparecem, layout não quebra.

## Saída

Seções, textos-chave, localização e testes.
