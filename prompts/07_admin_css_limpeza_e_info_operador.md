# Prompt 07 — CSS do Admin, Limpeza Visual e Informação Útil

## Objetivo

Melhorar Admin para operação real:
- corrigir partes brancas estranhas;
- remover ruído;
- destacar ações importantes;
- mostrar personagem e referência correta;
- preservar função.

## Prioridade do Admin

1. Próximo passo recomendado.
2. Estado atual.
3. Botões principais.
4. Resetar Arduino.
5. Mesa A/B fallback.
6. Personagem/resposta correta.
7. Logs essenciais.
8. Técnica avançada colapsável.

## Remover/esconder

Dados duplicados, debug bruto fora do técnico, textões, botões perigosos sem confirmação e ruído visual.

## Testes

Admin sem overflow grave, botões acessíveis, referência aparece, lint/build.

## Saída

O que estava ruim, o que foi limpo, informações escondidas, fluxo do operador e testes.
